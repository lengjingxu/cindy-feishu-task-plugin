# 飞书任务

将飞书应用关联到 Cindy 伙伴，自动接收指派任务并回报进度、结果和真实文件。看板支持按状态、清单、伙伴、创建人分组；详情展示日期、子任务、附件及产物。

0.15.13；最低客户端 Cindy 0.1.124，仅支持 macOS。最低版本来自公开接口核对，真实完整闭环已在当前安装的 0.1.130 构建通过，0.1.124 尚未单独实测。实际 0.1.130 构建来源与官方 tag 不同，完整限制见仓库兼容文档。

应用设置扫码连接，macOS Keychain 保存凭据；最多四个独立应用。插件退出后不继续执行。其他操作系统不支持，不降级为明文凭据文件。

伙伴回报时按 ghost_info 返回的实例身份调用 ghost_call，工具参数使用顶层 args。上传时仅交接本轮声明的文件，禁止复用包含历史文件的公共目录；Host 校验文件数量、文件名和字节数。

源码、兼容范围及下载：https://github.com/lengjingxu/cindy-feishu-task-plugin

跨设备授权、长期断线补收和循环两期自然执行尚未完整验收。本包不含任何账号、任务数据或私密回执。
