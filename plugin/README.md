# 飞书任务

在应用设置绑定飞书应用并选择 Cindy 伙伴。在飞书向该应用指派任务，关联伙伴执行后通过插件回报进度、结果和文件。

当前版本 0.15.5 仅交付开发源码。inspect_host_support 无需凭据，只检查当前适配器入口；不代表完整流程兼容。正式版本缺少动态鉴权票据上传、范围受限伙伴执行与 settled 回执；插件自管凭据尚未实现。没有可真实填写的完整兼容 minCindyVersion，故本阶段不提供安装包。

任务看板支持按状态、清单、伙伴、创建人分组。任务详情展示日期、子任务、附件及产物。预约优先使用开始日期；循环任务没有开始日期时使用截止日期。循环下一期由飞书生成。

源码、兼容性和版本下载：https://github.com/lengjingxu/cindy-feishu-task-plugin

真实两期循环执行、跨设备授权和长期断线补收仍待完整验收。本包不附带账号配置或任何真实任务数据。
